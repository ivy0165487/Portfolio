Process

How a commission moves from message to file.

  1. Send your rig and reference

    R16 or a custom rig works. Send any reference clips — game footage, mocap, or the kind of movement you're after — the same way you'd send me one of the gifs above.

    Frame 0

  2. Blocked-out pass

    Key poses only, usually back to you within a day or two, so you can catch direction issues before any time goes into polish.

    Draft

  3. Refine to final

    Spacing, weight, and foot planting polished frame by frame until the loop reads clean at full speed.

    Polish

  4. Receive your files

    Exported and ready to import into Studio, with one round of revisions included if something needs adjusting.

    Final
